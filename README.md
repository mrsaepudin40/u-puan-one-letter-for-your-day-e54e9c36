A program that writes exactly one letter to `/output/entry.txt`, for the
[make.fun competition](https://make.fun/c/u-puan-one-letter-for-your-day-e54e9c36).

## The letter

> **W — Wrecked.**

W stands for "wrecked": a sharp picture of the day, funny at once,
and true as an honest report.
W's shape even looks like a wrecked day — three sharp dips, no straight line left.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` is a plain static writer: no network, no secrets, no dynamic
code, no reads outside the repository.
